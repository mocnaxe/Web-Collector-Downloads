exan Websammler – Windows Test Downloads

Free, portable website archiving and offline browsing for Windows.

exan Websammler allows you to save accessible websites and linked resources locally, browse archived pages offline, and organize downloaded content.

Download

[Download exan Websammler 1.3.32 – Windows Test Release](https://github.com/mocnaxe/Web-Collector-Downloads/releases/tag/v1.3.32-test)

Download `Web-Collector-1.3.32-Windows-Test.zip` from the Assets section.

Getting Started

1. Download and extract the ZIP file.
2. Read the included instructions and license.
3. Start `exan-Websammler.exe`.
4. Begin with a small website you are authorized to archive.

No conventional installation is required. The application can also be used from a USB drive.

What We Would Like You to Test

Known Limitations

This is a test release. An occasional application crash has been observed and is still under investigation.

The application creates local website copies, not complete server backups. Some dynamic content, databases, and protected resources may be unavailable.
